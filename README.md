Video Game Tracker

A quick beginner project using Python and **Pandas** to analyze video game stats like playtime and ratings, just like an automated spreadsheet!

Features
* Loads game stats into a clean Pandas `DataFrame`
* Calculates total play hours and average review scores
* Filters top-rated games (9.0+)
* Groups total playtime by genre
* Exports the final report to `my_games.csv`
